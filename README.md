# NoName — бюро гострайтинга

This is a modern, interactive landing page for a ghostwriting agency. The page is built using HTML, CSS, and JavaScript with a sleek, dark-themed design.

## Features

- Modern dark mode design with gradient accents
- Smooth animations and transitions
- Responsive layout for all devices
- Interactive elements with hover effects
- Clean, professional typography
- Parallax scrolling effects
- Section reveal animations
- Typewriter effect for the tagline

## Files

- `index.html` - The main HTML file with the page structure
- `styles.css` - CSS styles for the page including animations
- `script.js` - JavaScript for interactive elements and animations
- `placeholder.html` - Notes about the placeholder image (can be deleted)

## How to Use

1. Simply open the `index.html` file in a web browser to view the page
2. To customize:
   - Replace the placeholder image with a real photo
   - Update the contact information (email, phone, social media links)
   - Modify text content in the HTML as needed
   - Adjust styling in the `styles.css` file

## Customization

The design uses CSS variables for easy customization:

```css
:root {
    --bg-color: #0f0f1a;
    --text-color: #e0e0e0;
    --accent-color: #ff4d5a;
    --secondary-color: #3a86ff;
    --tertiary-color: #8338ec;
    --card-bg: rgba(30, 30, 50, 0.7);
    --spacing-unit: 2rem;
}
```

You can change these values to update the color scheme of the entire site.
